The header lockup: the HK mark beside the business name and its descriptor.

```jsx
<Brand name="Harith Kavish" descriptor="Independent software business" logoSrc="assets/logo.png" href="/index.html" />
```

The mark is never recoloured or set on a dark plate — it is a gradient PNG on transparent. Use `wordmarkOnly` on product subdomains that carry their own name (e.g. Converse) so two marks never compete.
