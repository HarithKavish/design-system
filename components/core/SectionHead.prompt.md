The heading block that opens every section: optional eyebrow, a tightly-tracked title, and a lead that explains the section in one sentence.

```jsx
<SectionHead eyebrow="Ecosystem" title="A growing set of subdomains, each with one job."
             lead="Every subdomain is a focused, single-purpose service that shares the same design language." />
```

Titles are full sentences with a full stop. On inner pages the eyebrow is usually dropped, since the hero already named the page.
