The only button in the system: a fully rounded pill, in one of two weights.

```jsx
<Button variant="primary" href="/products.html">Explore Products</Button>
<Button variant="secondary" href="/status.html">View status</Button>
```

Pair them one-and-one in hero actions, primary first. Hover lifts the button 1px and darkens the accent; there is no scale, glow or gradient. Buttons go full width below 760px.
