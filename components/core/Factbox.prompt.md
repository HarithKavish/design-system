A hairline grid of label/value cells — the gap *is* the border, so the whole block reads as one ruled object.

```jsx
<Factbox facts={[{ label: 'Status', value: 'Live' }, { label: 'Since', value: '2026' }]} />
```

Use it to close an article or a product page. Two to four cells; it reflows at 200px per cell.
